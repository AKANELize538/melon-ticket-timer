# models/

Live2D 모델 파일을 여기에 넣으세요.

예시 구조:
```
models/
  mao/
    Mao.model3.json   ← 이 파일 경로를 앱 설정에서 입력
    Mao.moc3
    textures/
      texture_00.png
    motions/
      ...
```

앱에서 로드하는 방법:
⚙ 설정 → "Live2D 모델 불러오기" → URL 입력:
  https://[your-username].github.io/melon-ticket-timer/models/mao/Mao.model3.json
